# DCFNDU
*Understanding Cisco Data Center Foundations*

This repository is my personal vault for everything I learn while going through **DCFNDU – Understanding Cisco Data Center Foundations.** It’s where I break things down, write notes, and stash every insight that helps me make sense of data center tech.

DCFNDU covers the core skills needed for entry-level data center roles—networking, virtualization, storage networking, and unified computing. It also introduces Cisco ACI, automation, cloud concepts, and hands-on practice with Cisco NX-OS and UCS. In short: this repo tracks my journey as I explore the backbone of modern data centers and slowly turn the chaos into something I actually understand.
